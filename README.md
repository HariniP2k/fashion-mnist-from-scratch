# Fashion MNIST Neural Network From Scratch

This project implements a feedforward neural network from scratch using NumPy for classifying Fashion-MNIST images.

## Features
- Forward propagation
- Backpropagation
- SGD optimizer
- Momentum optimizer
- RMSProp optimizer
- Cross entropy loss
- MSE loss comparison
- WandB logging
- Confusion matrix visualization

## Dataset
Fashion-MNIST dataset from keras.datasets

## Technologies Used
- Python
- NumPy
- Matplotlib
- WandB
- Scikit-learn

## Accuracy
Achieved validation accuracy around 84-88%.

## Run
Open the notebook and run all cells sequentially.
